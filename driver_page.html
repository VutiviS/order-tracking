Switch on location

Deliveries are saved with the phone's location, so it must be allowed for this page.

Android (Chrome)
  1. Pull down from the top of the screen and switch Location on.
  2. Tap the icon left of the web address > Permissions > Location > Allow.
iPhone (Safari)
  1. Settings > Privacy & Security > Location Services on, and Safari Websites > While Using.
  2. Tap aA next to the web address > Website Settings > Location > Allow.
